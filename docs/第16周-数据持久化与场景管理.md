# 第 16 周：数据持久化与场景管理

## 1. 本周目标

在第 12 周生长记录和第 14 周交互编辑的基础上，实现植物预设、完整场景归档、记录点恢复及完整 OBJ/MTL 导出，形成“保存—载入—恢复—交换”的持久化闭环。

## 2. 完成内容

### 2.1 植物与环境预设

- 新增 `plantsim.preset` v1 格式，保存植物模型、初始植物状态、L-System 程序、环境参数、生长时间轴和物理开关。
- `EnvironmentParams` 支持完整 JSON 序列化与严格反序列化，包括多光源、向光/向地性、水分、营养、温度、风场和遮挡参数。
- 载入过程先在临时对象中校验全部数据，校验通过后才替换运行态，避免损坏当前场景。
- C++ 同时提供内存对象和文件接口：`createPreset`、`applyPreset`、`savePreset`、`loadPreset`。

### 2.2 完整场景归档与恢复

- 新增 `plantsim.scene` v1 格式，包含预设、完整生长记录、事件、关键帧及播放状态。
- `GrowthDataRecorder` 新增 v2 记录反序列化和文件载入，校验帧序、数值、指标及完整植物快照。
- 载入归档时恢复植物结构、环境、时间轴速度、事件、关键帧、编辑/网格版本和物理状态。
- 默认恢复归档保存时的精确当前场景；指定年龄时恢复最近的完整状态检查点，并保持暂停以便继续编辑或从该点分支模拟。
- 恢复后统一重建 PBD、Metaball 和 Marching Cubes 网格，并广播新的前端状态。

### 2.3 完整 OBJ/MTL 场景导出

- `MeshExporter` 新增内存序列化接口，可同时生成 OBJ 与 MTL 文本，文件接口改为原子写入。
- 场景导出包含 `branches` 和 `leaves` 两个网格组，以及树皮和四种叶片材质。
- 当低龄植物的实时预览网格尚未生成有效三角形时，导出流程自动使用更细的 Metaball 采样重建枝干，避免只导出叶片。
- 同时支持 C++ 文件导出和 WebSocket 浏览器下载。

### 2.4 WebSocket 与前端

新增命令：

| 命令 | 作用 |
| --- | --- |
| `persistence.preset.request` | 获取并下载植物/环境预设 |
| `persistence.preset.import` | 校验并载入预设 |
| `persistence.scene.request` | 获取完整场景归档 |
| `persistence.scene.import` | 载入场景归档，可指定恢复年龄 |
| `persistence.scene.restore` | 从当前记录恢复指定时间点 |
| `persistence.obj.request` | 获取完整 OBJ/MTL 导出包 |

Vue 控制台新增“场景与预设”面板，提供保存预设、选择预设文件、保存场景、选择场景文件、恢复当前时间点和导出 OBJ 六个入口。导入前先在浏览器端检查 JSON、Schema 和版本，再发送到引擎做完整校验。

│   ├── plant / initialPlant

- 保存后的植物形态、环境参数、回放记录和播放设置可完整恢复。
